# Схемы кораблей: системы, радары, пуск ракет

На странице корабля три связанных блока. Все они появляются автоматически по `id` корабля из `src/data/equipment.ts`.

| Блок | Откуда данные | Компонент |
|---|---|---|
| «Схема корабля и системы» | `shipSchemes` в `src/data/ships.ts` или `fleetSchemes` в `src/data/ships-fleet.ts` | `ShipExplorer` |
| «Радары и секторы обзора» | поле `sensor` у модулей той же схемы | `SensorScope` |
| «Выход ракет на траекторию» | `launchScenes` в `src/data/ships.ts` | `NavalLaunchDemo` |

## 1. Силуэт

Силуэт условный: он показывает расположение систем, а не обводы. Рисуется в координатах 1000 x 300, нос слева. Палуба обычного корабля на `y = 200`, полётная палуба авианосца на `y = 172`, ватерлиния на 240.

Фигуры собираются из готовых функций (`src/data/ships.ts`):

- `hull()` корпус обычного корабля, `carrierHull()` корпус авианосца, `carrierHull(true)` с носовым трамплином;
- `block(x0, x1, h)` надстройка высотой `h` над палубой; для авианосца четвёртым аргументом передать `CARRIER_DECK`;
- `tower(x0, x1, h)` пирамидальная мачта, `mast(x, h)` решётчатая мачта, `funnel(x0, x1, h)` труба;
- `gun(x)` артиллерийская башня стволом к носу, `gun(x, true)` стволом к корме;
- `hatch(x0, x1)` крышки вертикальных пусковых или подпалубных шахт.

Порядок слева направо: орудие, пусковые, надстройка с мачтой, трубы, кормовая надстройка, вертолётная площадка.

## 2. Системы

Модуль это метка на силуэте и карточка с характеристиками. Сначала проверить, нет ли готовой заготовки в объекте `P` в `ships-fleet.ts`: Phalanx, АК-630, Mk 45, Mk 41, Harpoon, Sea Sparrow, RAM, торпедные аппараты, вертолётная площадка, катапульты, авиагруппа, типовые радиолокаторы. Заготовка принимает координаты и при необходимости число установок, остальной текст уже написан.

Свой модуль: `m(id, kind, name, x, y, text, specs, extra)`.

- `kind`: `radar`, `missile`, `gun`, `ciws`, `torpedo`, `aviation`, `sonar`, `special` (доковая камера, водомёты и прочее).
- `x`, `y`: центр метки. Ставить на саму систему: на крышу надстройки, на мачту, на палубу. Метки не должны перекрываться: минимум 34 единицы между центрами.
- `specs`: пары «подпись, значение». Только то, что известно по открытым источникам; числа с «≈».
- `weaponId`: если образец есть в каталоге вооружения, карточка получит ссылку.
- `sensor`: для радиолокаторов, см. ниже.

На схеме 7-11 модулей. Одинаковые установки по бортам описываются одним модулем с количеством в `specs`.

## 3. Радиолокаторы

`sensor(id, name, role, type, half, extra)` из `src/data/sensors.ts`:

- `type`: `rotating` (вращающаяся антенна), `array` (неподвижные решётки, указать `faces`), `sector` (решётка с обзором в секторе), `track` (станция сопровождения и подсвета, узкий луч);
- `half`: полуширина сектора, 180 означает круговой обзор;
- `center`: направление центра сектора от носа по часовой стрелке (для кормовых станций 180);
- `rangeKm`, `period`, `band`: заполнять только при уверенных данных. Пустое поле на странице превращается в «открытых данных нет».

`id` радиолокатора должен быть уникален в пределах корабля.

## 4. Пуск ракет

В `launchScenes` указать, какие схемы показывать:

| Сцена | Когда |
|---|---|
| `vls-hot` | вертикальные установки с запуском двигателя в ячейке (Mk 41, Sylver) |
| `vls-cold` | выброс ракеты и запуск двигателя над палубой (С-300Ф, «Кинжал», «Редут», Sea Ceptor) |
| `cruise` | крылатые ракеты со сбросом ускорителя |
| `canister` | противокорабельные ракеты из наклонных контейнеров |
| `rail` | поворотные балочные и контейнерные пусковые |
| `sub` | пуск из-под воды |

Для корабля без управляемых ракет запись не нужна.

## Проверка

1. `node scripts/check-data.mjs`: строки «Корабли без схемы систем» и ошибки связности.
2. `npm run build`.
3. Открыть `/equipment/<id>/#ship`: метки стоят на своих системах и не перекрываются, фильтр по типу работает, карточка открывается и по метке, и по строке списка; кнопка «Показать сектор обзора» переключает схему радаров; раздел «Выход ракет на траекторию» показывает нужные вкладки.
4. Ширина 375 px: силуэт прокручивается внутри своего блока.
5. Состав вооружения указывать для основной серийной версии и писать об этом, если корабли серии различались.
