# Ангары авианесущих кораблей

Все данные в `src/data/hangars.ts`, отображение в `src/components/HangarDemo.astro`. Блок «Ангар» появляется на странице корабля автоматически, если для его `id` есть запись в `hangars`.

## Как добавить ангар кораблю

1. Убедиться, что корабль есть в `src/data/equipment.ts`, и взять его `id`.
2. Добавить запись в `hangars`:

```ts
'nimitz': {
  length: 208, width: 33, height: 7.6, elevators: 4,
  wing: [{ type: 'fa-18e', typical: 44 }, { type: 'e-2', typical: 4 }],
  note: 'Одна-две фразы об особенностях ангара.',
},
```

- `length`, `width`: размеры ангарной палубы в метрах по открытым источникам. `height` необязательна.
- `wing`: типы машин корабля и типовая авиагруппа. `typical` это число машин на корабле всего, включая стоящие на полётной палубе. В списке не больше пяти типов: у схемы пять цветов.
- `note`: не утверждать, сколько машин помещается «на самом деле», если нет источника. Число в ангаре считает модель.

Если размеры ангара в открытых источниках не найдены, запись не добавлять. Размеры не оценивать на глаз и не брать по аналогии с другим кораблём без пометки в `note`.

## Как добавить тип летательного аппарата

Строка в `aircraftTypes`:

```ts
a('f-35c', 'F-35C Lightning II', 'jet', 15.7, 9.5, 'Палубная версия с увеличенным складным крылом.'),
```

- `kind`: `jet`, `prop` или `helo`. От него зависит только силуэт.
- Длина и ширина в метрах в сложенном виде: со сложенным крылом, лопастями и хвостовой балкой. Если крыло не складывается, указывать полный размах и писать об этом в примечании.
- Один тип переиспользуется всеми кораблями, которые его несут. Перед добавлением проверить, нет ли его уже в списке.

## Как работает модель

Функция `pack` в `HangarDemo.astro` ставит машины рядами вдоль ангара с зазором 1 м (`GAP`), как прямоугольники, начиная с самых широких. Что не поместилось, считается стоящим на полётной палубе. Раскладка упрощённая: на корабле машины ставят плотнее и под углом, поэтому под схемой всегда есть пояснение. Число из модели нельзя выдавать за паспортную вместимость.

## Проверка

1. Каждый `type` в `wing` существует в `aircraftTypes`, каждый ключ `hangars` существует в `equipment.ts`.
2. `npm run build` без ошибок.
3. Открыть `/equipment/<id>/#hangar`: схема в масштабе, кнопки «+» и «-» меняют число машин, «Типовая авиагруппа» возвращает состав, показатели «В ангаре» и «Остаются на палубе» пересчитываются.
4. Ширина 375 px: схема прокручивается внутри своего блока, страница не получает горизонтальную прокрутку.
5. В текстах нет длинного тире и апострофов, числа округлены.
