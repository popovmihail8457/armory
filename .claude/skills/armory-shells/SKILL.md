# Снаряды и орудия «Арсенала»

Все данные лежат в одном файле `src/data/shells.ts`. Типы снарядов и орудия описаны один раз и переиспользуются: повторять их для каждой машины не нужно.

## Главное правило

Снаряд привязан к орудию, а не к машине. Машина получает весь набор снарядов через поле `platforms` орудия.

- **Новая машина с уже существующим орудием:** дописать её `id` в `platforms` нужного орудия в `guns`. Больше ничего не требуется: список снарядов, график и таблицы появятся на странице машины сами.
- **Новый снаряд к существующему орудию:** одна строка в `shells` с `gun: '<id орудия>'`.
- **Новое орудие:** строка в `guns`, затем его снаряды в `shells`.
- **Новый тип снаряда** нужен крайне редко. Сначала проверить, не подходит ли один из существующих.

## Существующие типы (поле `type`)

| id | Сокращение | Что это | Строится ли траектория |
|---|---|---|---|
| `apfsds` | БОПС | оперённый подкалиберный | да |
| `apds` | БПС | подкалиберный с отделяемым поддоном | да |
| `ap` | ББ | бронебойный калиберный | да |
| `heat` | КС | кумулятивный | да |
| `hesh` | БФС | бронебойно-фугасный | да |
| `he` | ОФС | осколочно-фугасный | да |
| `rocket` | АРС | активно-реактивный | нет |
| `missile` | ТУР | управляемая ракета через ствол | нет |

Описание принципа действия и сцена анимации боевой части заданы в `shellTypes` и подставляются по `type`.

## Семейства орудий (поле `gun`)

Перед добавлением орудия проверить, не входит ли оно в существующее семейство. Актуальный список: `guns` в `src/data/shells.ts`. Примеры:

- `2a46`: 125-мм гладкоствольные пушки Т-64, Т-72, Т-80, Т-90.
- `rh-120`: 120-мм гладкоствольные пушки НАТО (Leopard 2, M1 Abrams, K2, Merkava 4, Leclerc).
- `l7`: 105-мм L7 и M68 (M60, Leopard 1, ранний M1).
- `l11`: 120-мм британские нарезные L11 и L30.
- `2a42`: 30-мм 2А42 и 2А72. `m242`: 25-мм Bushmaster.
- `l52`: 155-мм гаубицы со стволом 52 калибра. `m185`, `2a33`, `2a64`, `2a31`: гаубицы M109, 2С3, 2С19, 2С1.

Поле `kind` (`tank`, `auto`, `low`, `howitzer`) определяет таблицу на `/ballistics/` и угол по умолчанию. Поле `weaponId` связывает орудие со страницей каталога `/weapons/<id>/`.

## Формат снаряда

```ts
{ id: '3bm42', name: '3БМ42 «Манго»', gun: '2a46', type: 'apfsds', v0: 1700, mass: 4.85, note: 'Одна фраза о снаряде.' }
```

- `v0`: начальная скорость, м/с. `mass`: масса в полёте, кг (для подкалиберных это масса летящего тела без поддона).
- `rangeKm`: только для гаубиц, опубликованная наибольшая дальность обычным снарядом.
- Если масса в полёте неизвестна или источники расходятся, поле `mass` не указывать: снаряд попадёт в список и таблицу, а траектория строиться не будет. Массу и скорость не придумывать.
- В `note` не использовать апострофы, длинное тире и эмодзи. Числа в тексте помечать «≈».

## Модель

`src/lib/ballistics.ts`: учебная модель с типовым коэффициентом формы для каждого типа (`SHAPE`). Коэффициенты сверены с опубликованными дальностями гаубиц (расхождение около 10 процентов). Менять их только после повторной сверки по нескольким гаубицам сразу, а не под один снаряд.

## Проверка

1. Каждый `gun` в `shells` существует в `guns`, каждый `id` в `platforms` существует в `src/data/equipment.ts`.
2. `npm run build` без ошибок.
3. Открыть страницу машины (`/equipment/<id>/#shells`) и `/ballistics/`: снаряд есть в списке, кнопка активна, если заданы `v0` и `mass`.
4. Для гаубицы сравнить дальность модели при угле около 45 градусов с `rangeKm`.
