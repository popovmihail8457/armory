# Сайт «Арсенал»

Статический справочник на Astro без UI-библиотек. Папка проекта: `Общее/armory-site`. Сборка: `npm run build`, разработка: `npm run dev -- --port 4400`.

## Структура

- `src/data/taxonomy.ts` - периоды, разделы, группы техники, метрики и их подписи. Любая новая группа или метрика добавляется здесь.
- `src/data/equipment.ts` - техника: `e(id, name, country, year, group, specs, text, wiki)`. Год это год принятия на вооружение, период определяется годом автоматически.
- `src/data/stories/{aviation,fleet,ground}.ts` - расширенное описание модели: `history`, `design`, `service`, `fact`, `variants`. Запись есть у каждой модели.
- `src/data/armament.ts` - вооружение на фото (метки в процентах от фото, состояние `visible|approx|hidden`).
- `src/data/defense.ts` и `src/data/radar.ts` - системы защиты, режимы радара и привязка к моделям.
- `src/data/weapons/` - каталог вооружения: `data.ts` (характеристики, носители), `texts.ts` (описание, принцип работы, особенности), `mods.ts` (модификации и отличия от предыдущей версии), `taxonomy.ts` (категории и метрики). Страницы: `/weapons/`, `/weapons/<id>/`, ссылки на технику строятся по `platforms`.
- `src/data/trajectory.ts` - сцены траекторий и карта группа техники -> сцена (`groupScene`); компонент `TrajectoryDemo`.
- `src/data/coverage.ts` - углы обзора радара, СПО и датчиков пуска ракет самолётов (`half` это полуугол, 180 означает круг); для машин без данных `status: none|undisclosed`. Схема: `CoverageDiagram`.
- `src/data/operations.ts` и `src/data/videos.ts` - участие в операциях и видеоролики Commons (встраиваются ссылкой, только PD/CC0); компонент `OperationsReel` (закреплённый видеофон).
- `src/lib/data.ts`, `src/lib/bg.ts` - выборки, ранги, выбор фото-фона из `public/bg/manifest.json`.
- `src/components/` - `BarChart`, `Scatter`, `Timeline`, `ArmamentMap`, `RadarDemo`, `DefenseDemo`, `TrajectoryDemo`, `StorySection`.
- `src/pages/` - главная, `periods/[era]/[domain]/[group]`, `equipment/[slug]`, `weapons/`, `radar`, `defense`, `sources`.
- `public/bg/` - фоновые фото и `manifest.json` с автором и лицензией.

## Как добавить

1. **Модель техники.** Добавить `e(...)` в `equipment.ts`, затем запись с тем же `id` в нужный файл `stories/`. Проверка: число id в `equipment.ts` совпадает с числом записей в `stories`.
2. **Группа.** Добавить в `groups` в `taxonomy.ts` (`id`, `domain`, `name`, `lead`, `metrics`). Страницы периода, раздела и группы создаются сами.
3. **Вооружение (каталог).** Добавить запись в `src/data/weapons/data.ts` и текст в `texts.ts`. Поле `platforms` содержит `id` моделей техники, ссылки строятся автоматически.
4. **Вооружение на фото.** Только на фото, где машина видна чётко. Метки ставить после просмотра файла. Неуверенное положение помечать `approx`, скрытое `hidden`.
5. **Анимация.** Сцены радара, защиты и траекторий это функции рисования на canvas. Новая сцена: функция + запись в реестре данных + вкладка. Анимация должна отключаться при `prefers-reduced-motion`.

## Правила проекта

- Никаких фиолетовых градиентов, эмодзи вместо иконок, ИИ-изображений, длинного тире (em dash), фейковых счётчиков, отзывов и метрик, анимации курсора, лишних анимаций при скролле. Допустимо: проявление блоков (opacity), рост столбцов, сцены радара и траекторий.
- Фото только реальные, только общественное достояние или CC0 (Wikimedia Commons), с автором и лицензией в `manifest.json` и на странице «О данных». Скачивать только после явного согласия пользователя.
- Числа округлены и помечены `≈`. Если не уверен в значении, не указывай его (поле необязательно) и не выдумывай. Источники: открытые данные.
- Описания и принципы работы только на уровне открытой энциклопедии. Без инструкций по изготовлению, обходу защиты и применению оружия.
- Секреты и токены не хранить. Публикацию, `git push` и отправку наружу выполняет пользователь или только после явного «да».

## Проверка перед сдачей

1. `npm run build` без ошибок.
2. Открыть изменённые страницы в браузере (`http://localhost:4400`), смотреть консоль на ошибки.
3. Проверить мобильную ширину 375 px: нет горизонтальной прокрутки.
4. Проверить, что у каждой новой модели есть `stories`, а у новой группы есть фото-фон (допустим фолбэк на раздел периода).
5. Поиск длинного тире: в файлах `src` не должно быть символа «—».
6. Локальный коммит с понятным сообщением.
